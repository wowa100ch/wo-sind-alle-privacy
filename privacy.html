Datenschutzerklärung für Wo sind alle?

Betreiber: Woldemar Riel. Kontakt: wosindalle.apk@gmail.com. Stand: 6. Oktober 2026.

Wo sind alle? ermöglicht Mitgliedern einer eingeladenen Familie, ihren Standort auf Anfrage miteinander zu teilen und Nachrichten auszutauschen. Es gibt keine fortlaufende Standortverfolgung. Eine Standortantwort kann auch bei geschlossener App erfolgen, wenn die Freigabe aktiviert und die Android-Berechtigung für den Standort im Hintergrund erteilt wurde. Die Freigabe lässt sich in den App-Einstellungen pausieren.

Verarbeitete Daten

  • Bei der Registrierung speichern wir den angegebenen Namen, eine zufällige Nutzerkennung, einen Hash des Zugangstokens, die Familienzugehörigkeit und den Freigabestatus. Der Server speichert einen Firebase-Push-Token für die Zustellung einmaliger Standortanfragen. Zugangstoken und Push-Token liegen auch auf dem Gerät.
  • Bei einer Standortanfrage erhält der Server Koordinaten, Genauigkeit und Messzeitpunkt der antwortenden Person. Nur die anfragende Person derselben Familie kann die Antwort abrufen. Der Server hält Anfrageergebnisse vorübergehend im Arbeitsspeicher; abgelaufene Anfragen werden nach ungefähr drei Minuten entfernt. Es wird kein dauerhafter Standortverlauf auf dem Server gespeichert. Die App kann zuletzt berechnete Entfernungen lokal speichern.
  • Gruppen- und persönliche Nachrichten enthalten Absender, Empfänger beziehungsweise Familiengruppe, Text und Zeitpunkt. Der Server speichert höchstens die letzten 300 Nachrichten insgesamt. Ältere Nachrichten werden durch neue verdrängt. Bei Kontolöschung werden alle von diesem Konto gesendeten und alle persönlich an dieses Konto gerichteten Nachrichten entfernt. Gruppennachrichten sind für die Familie sichtbar, persönliche nur für Absender und Empfänger.
  • Einladungscodes sind zehn Minuten gültig. Der Server speichert einen Hash des Codes und die zugehörige Familie und einladende Person. Die IP-Adresse wird kurzzeitig verwendet, um Registrierungsanfragen zu begrenzen. Der Hosting-Anbieter kann technische Verbindungsdaten verarbeiten.

Dienste und Empfänger

Der Familienserver läuft bei Render. Dauerhaft gespeicherte Konten, Familienbeziehungen, Push-Tokens und Nachrichten liegen in Google Firestore. Firebase Cloud Messaging stellt Push-Anfragen zu; sie enthalten eine Anfragekennung und Ablaufzeit, keine Koordinaten. Die Karte lädt Kacheln von tile.openstreetmap.org; dabei können IP-Adresse und betrachteter Kartenausschnitt an diesen Dienst übertragen werden. Diese öffentliche Informationsseite wird über GitHub Pages bereitgestellt; GitHub kann dabei die IP-Adresse für Sicherheitszwecke protokollieren. Standortantworten werden an die anfragenden Familienmitglieder weitergegeben. Die App enthält keine Werbung und verkauft keine personenbezogenen Daten.

Kontrolle, Aufbewahrung und Löschung

In der App können Nutzer die Standortfreigabe pausieren, die Familie verlassen oder „Konto und Daten löschen“ wählen. Die Kontolöschung entfernt Registrierung, serverseitigen Push-Token, eigene Nachrichten, persönlich an das Konto gerichtete Nachrichten und offene Einladungen dieses Kontos. Andere Familienmitglieder behalten ihre eigenen Gruppennachrichten. Die App entfernt dabei die lokal gespeicherte Anmeldung und Einstellungen.

Ohne installierte App kann die Löschung über die Seite zur Kontolöschung angefragt werden. Zur Vermeidung unbefugter Löschungen kann eine Bestätigung der Kontozugehörigkeit erforderlich sein; eine Neuinstallation der App ist dafür nicht nötig.

Sicherheit und Änderungen

Die App verbindet sich mit dem Familienserver über HTTPS. Der Server prüft die Familienzugehörigkeit vor der Herausgabe von Nachrichten und Standortantworten. Zugangsdaten sind von Android-Backups und Geräteübertragungen ausgeschlossen. Änderungen dieser Erklärung werden auf dieser Seite veröffentlicht. Fragen zur Datenverarbeitung können an wosindalle.apk@gmail.com gerichtet werden.
